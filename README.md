## 📌 Overview
This repository contains my solutions for the **Week 6 Assignment** in the PLP Academy [Database Systems](https://academy.powerlearnprojectafrica.org/module/6a259fb4911523cdf74594d3?study=false) module. The project demonstrates practical proficiency in combining data from multiple related tables using different types of SQL joins (`INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN`).

---

## 🎯 Learning Objectives
- Implement `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN` statements effectively in SQL.
- Retrieve and correlate data across related relational database tables.
- Work with relational schemas involving entities such as employees, offices, products, product lines, customers, and orders.
- Structure and organize production-ready SQL scripts.
